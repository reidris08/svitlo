# Світло: графік відключень (Полтаваобленерго)

Особистий застосунок для iPhone. Показує, скільки лишилося до ввімкнення або вимкнення світла у вигляді горизонтальної смуги, графік на сьогодні й завтра та попередження, коли діють **ГАВ / СГАВ**. Є також віджет на головний екран і екран блокування.

Усе працює безкоштовно на GitHub.

```
svitlo/
├── index.html, search.js    ← застосунок і пошук черги за адресою
├── manifest.webmanifest, sw.js, icon-*.png
├── data/addresses.json      ← перелік адрес по чергах (з PDF обленерго)
├── scripts/update.mjs       ← збирає графік і статус ГАВ
├── scripts/addresses.py     ← перетворює PDF з адресами на data/addresses.json
├── scripts/fetch_pdf.py     ← шукає на сайті новий PDF з адресами
├── .github/workflows/       ← автозапуск: графік кожні 10 хв, адреси щодня
├── pdf/                     ← сюди можна вручну покласти новий PDF з адресами
└── widget/svitlo-widget.js  ← віджет для програми Scriptable
```

---

## Крок 1. Репозиторій на GitHub (≈10 хв, один раз)

1. Зареєструйтеся на <https://github.com> (безкоштовно).
2. Натисніть **+ → New repository**:
   - Repository name: `svitlo`
   - **Public** (безкоштовний GitHub Pages працює лише з публічними репозиторіями; вашої адреси там не буде, вона зберігається тільки на телефоні)
   - **Create repository**
3. На сторінці репозиторію натисніть **uploading an existing file** (або **Add file → Upload files**) і перетягніть **увесь вміст** розпакованої папки `svitlo`. Потім натисніть **Commit changes**.

   > ⚠️ Папка `.github` прихована. На Mac у Finder натисніть **Cmd + Shift + .**, щоб її побачити. Якщо вона все одно не завантажилася: **Add file → Create new file**, у полі імені введіть `.github/workflows/update.yml`, вставте вміст файлу `update.yml` і натисніть **Commit**.

## Крок 2. Увімкнути автоматичне оновлення даних

1. Вкладка **Settings → Actions → General**. Унизу, у **Workflow permissions**, оберіть **Read and write permissions** і натисніть **Save**.
2. Вкладка **Actions**. Якщо з'явиться кнопка «I understand my workflows… enable them», натисніть її.
3. Ліворуч оберіть **Оновлення графіка → Run workflow**.
4. Приблизно за хвилину в репозиторії з'явиться папка `data` з файлами `schedule.json` і `status.json`. Далі вони оновлюватимуться самі кожні ~10 хв.

## Крок 3. Увімкнути сайт (GitHub Pages)

1. **Settings → Pages**.
2. Source: **Deploy from a branch**, Branch: **main**, папка **/ (root)**, потім **Save**.
3. За 1–2 хв там з'явиться адреса: `https://ВАШ-ЛОГІН.github.io/svitlo/`

## Крок 4. Встановити на iPhone

1. Відкрийте цю адресу в **Safari**.
2. Натисніть **Поділитися → На початковий екран → Додати**.
3. Відкрийте «Світло» з головного екрана, введіть адресу й оберіть чергу.

### Як працює адреса → черга
- Введіть адресу у форматі **місто, вулиця, будинок**, наприклад `Полтава, Злагоди 25`. Застосунок шукає її в переліку адрес Полтаваобленерго (PDF «Графік погодинного відключення») і сам підставляє чергу.
- Якщо вулицю поділено між кількома чергами або номер будинку в PDF не вказано, застосунок покаже варіанти з фрагментом тексту документа. Тоді оберіть свій.
- Якщо адреси немає в переліку, її можна обрати вручну («Обрати чергу вручну»).
- Адреси й черги зберігаються **лише на телефоні**. Можна зберегти кілька адрес і перемикатися між ними вгорі. Якщо натиснути на активну адресу ще раз, вона відкриється для редагування.

### Оновлення переліку адрес
Щодня GitHub перевіряє сторінку обленерго з переліком адрес. Якщо там з'явився новий PDF, він сам перетворюється на `data/addresses.json`.

Якщо сайт не пускає сервери GitHub (у вкладці **Actions** з'явиться жовте попередження «Сайт poe.pl.ua недоступний»), зробіть так:
1. Завантажте новий PDF із сайту на телефон або комп'ютер.
2. У репозиторії відкрийте папку `pdf` → **Add file → Upload files** → додайте PDF → **Commit changes**.
3. Приблизно за хвилину перелік адрес оновиться сам.

## Крок 5. Віджет на головний екран (iPhone)

1. Встановіть безкоштовну програму **Scriptable** з App Store.
2. У Scriptable натисніть **+**, вставте весь вміст файлу `widget/svitlo-widget.js` і назвіть скрипт `Світло`.
3. У рядку `const BASE_URL = "https://ВАШ-ЛОГІН.github.io/svitlo/";` замініть `ВАШ-ЛОГІН` на свій логін GitHub.
4. Натисніть ▶︎ → **Обрати чергу**. Черга збережеться.
5. На головному екрані: довге натискання → **Редагувати → Додати віджет → Scriptable** (малий або середній). Натисніть на віджет → Script: **Світло**.
   - Поле **Parameter** можна лишити порожнім або вписати чергу (напр. `3.2`), якщо потрібен віджет для іншої адреси.
6. На екрані блокування: довге натискання → **Налаштувати → Екран блокування → віджети → Scriptable** (прямокутний) → Script: **Світло**.

Таймер у віджеті рахує щосекунди. Дані віджет оновлює сам: iOS дозволяє це приблизно раз на 10–15 хв.

## Звідки дані

- **Погодинний графік (ГПВ)**: офіційний сайт poe.pl.ua через відкритий набір даних
  [findme88/poltava-outage-data](https://github.com/findme88/poltava-outage-data). Він перевіряє сайт кожні ~5 хв (12 підчерг, крок 30 хв). Півгодини «перемикання світла» (час, потрібний обленерго, щоб увімкнути світло) показано окремо.
- **ГАВ / СГАВ**: останні дописи офіційного Telegram-каналу [@poltavaOE](https://t.me/poltavaOE). Якщо за останні 18 год був допис про застосування ГАВ або СГАВ і після нього їх не скасували, з'являється плашка поверх смуги. Натисніть на неї, щоб відкрити сам допис.

- **Черга за адресою**: перелік адрес з PDF Полтаваобленерго (зараз «HPV_26_27-sajt-8.10.2026.pdf», період 01.10.2026–01.04.2027, 1245 записів).

## Обмеження

- Це **план**, а не фактичний стан мережі. Аварійні вимкнення можуть не збігатися з графіком.
- ГАВ визначаються автоматично за текстом повідомлень. Якщо Полтаваобленерго сформулює повідомлення незвично, плашка може не з'явитися або запізнитися.
- PDF з адресами написаний вільним текстом, тому пошук черги іноді може помилитися. Звіряйте результат із фрагментом документа, який показує застосунок.
- GitHub іноді запускає оновлення із затримкою на кілька хвилин.
- Якщо репозиторій довго не змінюється, GitHub може призупинити автозапуск. Тоді у вкладці **Actions** натисніть **Enable workflow**.
